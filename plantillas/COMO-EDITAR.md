# Saravia Ubilla — 8 plantillas editables para Instagram

**Archivo:** `saraviaubilla-plantillas.pptx` (8 diapositivas de 1080 × 1350, el formato vertical de Instagram).
**Vista previa:** carpeta `vista-previa` y `saraviaubilla-plantillas.pdf`.

| # | Plantilla | Para qué sirve |
|---|---|---|
| 1 | Propiedad disponible | Foto grande, operación, tipo, título, ubicación, dormitorios, baños, m², precio y botón |
| 2 | Propiedad vendida / alquilada | Foto de fondo con el sello VENDIDA (o ALQUILADA / RESERVADA) |
| 3 | Próximo remate | Fecha destacada, nombre, hora, lugar, modalidad, exhibición y botón de WhatsApp |
| 4 | Remate: lotes destacados | 3 fotos de lotes, fecha, lugar y botón |
| 5 | Servicio / dato | Ícono, título grande y texto breve |
| 6 | Consejos / lista | Título y 3 puntos numerados |
| 7 | Frase / testimonio | Fondo celeste con una cita |
| 8 | Aviso / contacto | Novedades, horarios o feriados, con WhatsApp y web |

## Cómo usarlas

**En Canva (recomendado):**
1. Canva → **Crear un diseño → Importar archivo** → elegir `saraviaubilla-plantillas.pptx`.
2. Se abre con las 8 páginas editables.
3. **Texto:** doble clic y escribir.
4. **Foto:** arrastrar la foto nueva encima de la de ejemplo.
5. **Descargar:** Compartir → Descargar → PNG.

**En PowerPoint o Keynote:**
- **Texto:** clic y escribir.
- **Foto:** clic derecho → **Cambiar imagen**.
- **Exportar:** Archivo → Exportar → PNG (solo la diapositiva actual).

**En Google Slides:** Archivo → Importar diapositivas → subir el .pptx. Para guardar el posteo: Archivo → Descargar → PNG.

## Reglas para que queden siempre prolijos
- Reemplazá **todo lo que está entre [corchetes]**, incluidos los corchetes.
- No cambies los colores ni las tipografías: ya son los de la marca (azul marino #1E3246, celeste #559FCF y blanco; **Plus Jakarta Sans** para títulos e **Inter** para textos).
  - Canva y Google Slides ya las tienen.
  - En PowerPoint, si no se ven igual, instalalas gratis desde fonts.google.com.
- **Títulos cortos:** dos o tres líneas como máximo.
- Usá **fotos reales, horizontales y bien iluminadas**.
- **Íconos:** la carpeta `iconos` tiene otros (casa, martillo, escudo, calendario, pin…) en 4 colores. Para cambiar uno, reemplazá la imagen.
- **Publicá solo datos confirmados:** fechas, precios, bases y condiciones de remates.
- **Testimonios:** solo reales y con autorización.
- Cada diapositiva tiene una **nota** con indicaciones (Ver → Notas).
