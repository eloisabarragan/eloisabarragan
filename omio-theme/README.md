# Tema WordPress — Omio Iluminación

## Instalación
1. WordPress → Apariencia → Temas → Añadir nuevo → Subir tema → `omio-theme.zip` → Activar.
2. Instalá/activá **WooCommerce** (la portada muestra los productos más vendidos automáticamente).
3. Ajustes → Lectura → "Una página estática" y elegí cualquier página como portada (el tema usa `front-page.php`).
4. Apariencia → Personalizar → **Omio**: colores de marca, tipografías (nombres de Google Fonts), textos de portada, contacto y redes.
5. Apariencia → Personalizar → Identidad del sitio: subí el logo oficial.
6. Apariencia → Menús: asigná un menú a "Menú principal" (si no, se usa uno por defecto).

## Categorías de WooCommerce que enlaza la portada (slugs)
`iluminacion-industrial`, `iluminacion-hogar`, `iluminacion-deportiva`, `iluminacion-solar`, `iluminacion-vial`, `linea-industrial-y-hogar`.
Si un slug no existe, el enlace va a la tienda. Las páginas `/linea-industrial-intemperie/` y `/linea-profesional/` se enlazan tal cual.
